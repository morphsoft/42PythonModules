# Python Modules · 42 São Paulo

Os exercícios dos módulos de Python da 42 e o projeto **A-Maze-ing**, com um **guia interativo
para cada módulo**. Os guias foram feitos para quem está começando em Python agora: cada um explica
o módulo do zero, com comparações do dia a dia, o código de verdade rodando passo a passo, cards
de conceitos, desafios no estilo da defesa e um quiz.

> **Os links dos guias são privados.** Se o link não abrir para você, peça acesso a quem mantém
> o repositório: cada guia é compartilhado pelo menu **Share** da própria página.

### O que tem em cada guia

- **Uma seção por exercício**, com a ideia principal explicada com uma comparação do dia a dia e um
  brinquedo interativo pra testar a ideia.
- **Explore o código**: o programa de verdade, gravado linha por linha. Você clica num trecho e vê
  a explicação, ou executa passo a passo vendo as variáveis mudarem e o terminal imprimindo.
- **O Python do módulo**: cards de conceitos. Cada card abre uma explicação com calma: em uma frase,
  uma comparação, um exemplo, onde aparece no código e o erro mais comum.
- **Regras do PDF e onde elas moram**: cada regra do subject ligada ao arquivo que a cumpre.
- **Desafios de defesa**: mudanças pequenas no estilo da avaliação, com dica escondida.
- **Quiz** no fim, com a explicação de cada resposta.

## Por onde começar

Siga a ordem dos módulos, começando pelo **Módulo 0**: cada um usa o que veio antes.

1. Abra o guia do módulo e leia **Antes de começar**.
2. Em cada exercício: leia a ideia, brinque com o brinquedo, abra **Explore o código** e rode passo a passo.
3. Abra o código de verdade na pasta do módulo e rode você mesmo (veja abaixo).
4. Faça os **desafios de defesa** numa cópia do arquivo.
5. Termine com o **quiz**. Errou? A explicação da resposta diz onde revisar.

## Regras que valem para todos os módulos

- Python **3.10** ou mais novo.
- O código segue o padrão **flake8**.
- **Type hints** em todas as funções e métodos, conferidos com **mypy**.
- O programa **nunca quebra** com traceback: os erros são tratados e viram mensagens.
- Só vale usar o que o exercício autoriza (seção **Authorized** de cada exercício no PDF).
- Pastas e arquivos com o nome exato que o PDF pede.

## Como rodar e conferir

```bash
python3 Module2/ex0/ft_first_exception.py       # rodar um exercício
python3 -m flake8 Module2                       # estilo
cd Module2/ex0 && python3 -m mypy . --disallow-untyped-defs --check-untyped-defs   # tipos
```

Os exercícios com argumentos ou com entrada pelo teclado estão explicados no guia de cada módulo.
O A-Maze-ing tem os próprios comandos (`make run`, `make test`, `make tester`): veja o
[README dele](A-Maze-ing/README.md).
